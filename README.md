# KeshVeda

Static product website built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Deploy with GitHub Pages

The workflow in `.github/workflows/deploy-pages.yml` deploys this directory whenever
changes are pushed to `main`. In the repository settings, set **Pages → Build and
deployment → Source** to **GitHub Actions**. After the first successful workflow run,
GitHub Pages provides the public site URL in the workflow run and repository Pages
settings.
